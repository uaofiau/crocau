# crocau

Портабл-оболочка для [croc](https://github.com/schollz/croc): передача файлов, папок и текста между устройствами через интернет со **своим паролем**, со сквозным шифрованием (PAKE). Две вкладки: «Отправить» и «Получить».

Сейчас: **Windows 7 и новее, 32-битная сборка** (работает и на 64-битных системах). Остальные платформы — после отладки Windows.

## Запуск

1. Скачайте `crocau-win32.zip` из раздела Releases (`latest`) и распакуйте в любую папку (можно на флешку).
2. Запустите `crocau.bat`.
3. Если окно не появилось — запустите `crocau-debug.bat`, там виден текст ошибки. Ошибки также пишутся в `crocau-error.log`.

Установка не нужна. Все данные (настройки `crocau.ini`, конфиг croc `croc-config\`) лежат рядом с программой. Пароль передачи нигде не сохраняется.

## Как пользоваться

- **Отправить:** добавьте файлы/папки (кнопки или перетаскивание мышью) либо переключитесь на «Текст». Введите пароль (от 6 символов) или нажмите «Случайный». Нажмите «Отправить» и передайте пароль получателю.
- **Получить:** введите тот же пароль, выберите «Файлы и папки» (и папку сохранения) или «Текст», нажмите «Получить». Полученный текст появится в окне, его можно скопировать.
- Для текста есть ограничение длины командной строки Windows (около 30 000 символов); большой текст отправляйте файлом.

## Жёсткие блокировки

Публичный relay croc часто блокируют. Надёжнее поднять **свой relay** на VPS:

```
croc relay --port 443 --ports 443,444,445,446,447
```

и указать его адрес (`ваш.сервер:443`) на вкладке «Настройки». Важно: должны быть открыты **все** перечисленные порты. Если нужен прокси — укажите `socks5://host:port` или `http://host:port` там же. Пароль relay (`--pass`) тоже задаётся в настройках.

## Сборка

Собирается GitHub Actions (`.github/workflows/build.yml`): `croc v10.0.12` компилируется Go 1.20 (последний Go, поддерживающий Windows 7) под `windows/386`, затем на Windows-runner выполняется самотест (`crocau.ps1 -SelfTest`: локальный relay, передача текста и файлов с проверкой содержимого).
